# ⚡ RAKESH-CORE // Developer Portfolio & Systems Architecture Console

A high-performance, responsive developer portfolio designed with a Cyberpunk Terminal / Telemetry HUD aesthetic. Built with **React**, **TypeScript**, **Tailwind CSS**, **GSAP**, and **D3.js**, this console presents real-world engineering projects, systems architecture schematics, interactive telemetry, and verified credentials with minimal recruiter friction.

---

## 🛰️ Core Features

- **Floating Telemetry HUD:** Fixed borderless top uplink navigation bar (`$ops`, `$principles`, `$systems`, `$signals`, `$architect`, `$comms`) and persistent bottom status ticker monitoring live coordinates, real-time FPS, and simulated system load via `requestAnimationFrame`.
- **Interactive Architecture Schematics:** Modular architectural flow diagrams (FIG. 1–4) for distributed systems, collaborative real-time tooling, and vector visualizers with active pipeline indicators.
- **Frictionless Communication Routing:** Responsive cross-platform email action dock that automatically routes to direct Gmail Web compose on desktop or triggers default mail clients on mobile devices.
- **Verified Credibility Matrix:** Direct PDF credential viewers and expandable certification drawers for standardized assessments and hackathons without third-party redirection.
- **Hardware-Accelerated Transitions:** Smooth viewport sliding, interactive glow micro-states, and backdrop-blur HUD framing optimized for sub-16ms frame budgets.

## 📁 System Modules

- `00 / HERO TERMINAL` — Interactive terminal simulator with JSON schema specs and quick resume download links.
- `01 / OPERATING PRINCIPLES` — Engineering philosophy focused on full-stack ownership, deterministic architecture, and scalable design.
- `02 / DEPLOYED SYSTEMS` — Detailed breakdowns and architecture schematics for production apps:
  - **IncidentHub AI:** Multi-tenant incident intelligence platform with Redis locks and RBAC isolation.
  - **SyncPad:** Real-time collaborative code editor powered by Yjs CRDTs and client-side Pyodide WASM.
  - **PortfolioPulse:** Deterministic hiring readiness auditor using GitHub REST API and headless DOM crawlers.
  - **Kohli Analytics:** Interactive cricket vector sports intelligence engine built with D3.js and hardware-accelerated motion.
- `03 / OPEN-SOURCE SIGNALS` — Direct repository cards, star metrics, and technical contributions built in the open.
- `04 / THE ARCHITECT & CAPABILITY MATRIX` — Operator spec sheet, verified internship experience, 170+ LeetCode milestones, and full-stack technical competencies.
- `05 / ESTABLISH COMMS` — Minimal terminal uplink and social transmission channels.
- `MISSION DEBRIEF` — Slide deck summary matrix and session rewind dock.
